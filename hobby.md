# Мой пет-проект

Идея: Телеграм-бот для напоминания о поливе цветов.

Стек: Python (aiogram)

Цель: научиться работать с API Telegram и асинхронностью.

## Сроки реализации
- **Неделя 1:** Изучение документации aiogram, настройка окружения.
- **Неделя 2:** Реализация базовых команд (/start, /help) и подключение к БД.
- **Неделя 3:** Добавление функционала напоминаний (cron-задачи).
- **Неделя 4:** Тестирование, деплой на сервер, написание README.

# Git в IDE vs Терминал

### 3 вещи, которые удобны в VS Code:
1. Визуальное отображение diff до коммита.
2. Удобное разрешение конфликтов слияния через кнопки.
3. Расширение GitLens, которое прямо в коде показывает авторgit add ide_notes.mdа каждой строки.

### 1 вещь, которую удобнее делать в терминале:
1. Сложные операции с историей (например, интерактивный rebase или cherry-pick), а также работа на удаленных серверах по SSH, где нет графического интерфейса.

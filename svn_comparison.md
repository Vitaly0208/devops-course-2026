# Сравнение Git и SVN

1. **Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?**
В Git ветка — это просто легковесный указатель на конкретный коммит. Её создание занимает миллисекунды. В SVN ветка — это физическое копирование всей директории с файлами на сервере, что требует времени и ресурсов.

2. **Можно ли в SVN сделать коммит без интернета? Почему?**
Нет. SVN — централизованная система. Чтобы зафиксировать изменения , нужен постоянный доступ к центральному серверу. Git позволяет коммитить локально, а на сервер отправлять позже .

3. **В каких сценариях SVN до сих пор может быть предпочтительнее Git?**
В старых legacy-проектах (госсектор, банки), где требуется жесткий централизованный контроль, или для работы с очень большими бинарными файлами, которые Git плохо обрабатывает, а SVN позволяет блокировать файлы , чтобы два человека не редактировали их одновременно.
